Overview & Platform Objective

GreenBore AI is a full-stack AI engineering platform built for analyzing deep well-log data and generating explainable drilling recommendations. It combines geological simulation, machine learning, and retrieval-augmented generation into a single decision-support tool.

Core Engineering Features

01 // INTERACTIVE 3D SUBSURFACE VISUALIZATION

Built with React Three Fiber and Three.js. Renders rock strata, wellbore trajectories, fractures, and aquifers with an exploded-view inspector, plane slicers, and toggleable geological layers.

02 // MULTI-TRACK PETROPHYSICAL LOG VIEWER

High-performance SVG-based charts displaying gamma-ray, resistivity, porosity, density, and sonic telemetry. Cross-linked in real-time to the 3D model viewport to inspect subsurface anomalies instantly.

03 // GEOLOGICAL SIMULATION ENGINE

Generates realistic synthetic strata, fracture networks, and aquifer data with configurable sensor noise and automated feature engineering (moving averages, porosity-resistivity ratios). Data can be exported seamlessly as CSV, JSON, or Apache Parquet.

04 // ML MODEL CATALOG & PROMOTION SYSTEM

Trains and registers RandomForest and XGBoost classifiers for formation lithology and groundwater potential prediction. Tracks hyperparameter history, feature importances, and evaluation metrics with a promotion workflow for production models.

05 // RAG DECISION CO-PILOT

An intelligent assistant backed by a self-healing PostgreSQL vector database (pgvector) containing domain geological literature. Uses Google Gemini API for synthesis with a deterministic local fallback when offline.
