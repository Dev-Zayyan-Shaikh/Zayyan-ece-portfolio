HARDWARE ARCHITECTURE & CONTROL FLOW

Physical Closed-Loop:
AQI, Temperature, and Humidity sensors continuous polling → ESP32 ADC/UART → Hysteresis evaluation logic → 2-Channel Relay Switching → Intake Fan & Ionizer Actuation.

Digital Twin Loop:
ESP32 internal WebServer hosts asynchronous WebSocket API → Real-time telemetry broadcast to browser → Remote manual relay overrides.

Overview & System Objective

Indoor particulate pollution (PM2.5 and PM10) presents significant health risks. Standard purifiers often run continuously at fixed speeds regardless of actual ambient air quality, consuming excess power and prematurely wearing filter elements.

This system uses an ESP32 microcontroller to continuously monitor air quality index (AQI), ambient temperature, and relative humidity. Based on user-configured thresholds, the system automatically triggers dynamic air filtration via an intake fan and activates a high-voltage electrostatic ionizer.

Hardware Implementation

  • ESP32 Microcontroller: Central control unit running an embedded C++ firmware with non-blocking timing loops and local web server.
  • AQI Particulate Sensor: Laser-based particle sensor measuring PM2.5 and PM10 concentrations via serial interface.
  • DHT22 Sensor: Digital temperature and humidity sensor providing ambient environment metrics.
  • 2-Channel Relay Module: Optocoupler-isolated relays for high-voltage isolation.
    • Channel 1: Controls main intake fan power.
    • Channel 2: Controls the high-voltage ionizer power supply.
  • Ionizer & Aluminum Collector Plate: Generates negative ions to charge suspended airborne particles, attracting them to a grounded aluminum collection plate for silent particulate precipitation.
  • Exhaust / Auxiliary Fan Mechanism: Modular mechanical mounting supporting room-specific exhaust air extraction.

Control Logic & Hysteresis Filtering

To prevent rapid relay chattering near the AQI threshold point (which can damage relay contacts and mechanical fans), the ESP32 implements a noise-immune hysteresis control algorithm:

ON Point  = Threshold + Hysteresis (e.g. 50 + 10 = 60 AQI)
OFF Point = Threshold - Hysteresis (e.g. 50 - 10 = 40 AQI)

The relay turns ON only when AQI rises to 60 or above, and stays ON until AQI drops to 40 or below.
